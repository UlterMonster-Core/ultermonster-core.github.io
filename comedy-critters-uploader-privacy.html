Privacy Policy — Comedy Critters Uploader

Effective: October 1, 2026

Comedy Critters Uploader is a private tool used by the owner of the Comedy Critters YouTube channel to publish videos to that channel via the YouTube Data API. It is not offered to the public.

Data we access

Through the YouTube Data API (scope youtube.upload), the app can upload videos and set thumbnails on the owner's own YouTube channel. It does not access any other Google account data — no email, no contacts, no other channels.

How data is used

Access is used solely to publish the owner's own videos and thumbnails to the Comedy Critters channel. Uploaded content is the owner's own material. No data is shared with, sold to, or disclosed to any third party.

Data storage

OAuth tokens authorizing this access are stored securely and used only to authenticate API calls for the purposes above. No video content is retained by the app beyond the upload itself.
